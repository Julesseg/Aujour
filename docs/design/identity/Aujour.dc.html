ANNOTATION 01 — PILL ↔ CALENDAR
One continuous, interruptible drag on the pill. Progress p ∈ [0,2] maps to a single glass container that grows downward: p=0 pill (h 44, w 214, r 22) → p=1 week strip (h 112) → p=2 month grid (h 362, w 370, r 26).
The week strip is not a separate view — it is the month grid translated so the current week sits under the weekday labels (−88px → 0). Nothing cross-fades; the same cells travel.
Release snaps to the nearest detent, spring stiffness 320 · damping 30 (CSS: .42s cubic-bezier(.32,.72,0,1)). Reverse mid-flight is honoured — no queued animation. Tap steps pill → week → month → pill.
ANNOTATION 02 — SYNTAX REVEAL
Tap any line. Only the cursor's line swaps to raw markdown; every other line stays rendered. The swap is same-baseline: the raw face is a mono at the same optical size, and markers are --ink-3 so the line's weight barely changes.
No height jump: block glyphs (checkbox, quote rule, heading size) hold the line's box while their markers appear. Reveal 120ms ease-out, hide 180ms — leaving is calmer than arriving.
